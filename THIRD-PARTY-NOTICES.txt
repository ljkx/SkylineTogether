1. LZ4 block format
-------------------

SkylineTogether.Core contains its own C# implementation of the LZ4 block format (ManagedLz4Compressor). It was written
from the LZ4 block format description and produces standard LZ4 blocks; no LZ4 source code is included.

  LZ4 - Fast LZ compression algorithm
  Copyright (c) Yann Collet. All rights reserved.
  https://github.com/lz4/lz4


2. xxHash (XXH64 and XXH3)
--------------------------

SkylineTogether.Core contains its own C# implementations of the XXH64 and XXH3 (128-bit) hash functions, written from
the xxHash specification. To produce the same hash values as every other implementation, they use the algorithm's
published constants, including the default XXH3 secret. No xxHash source code is included.

  xxHash - Extremely Fast Hash algorithm
