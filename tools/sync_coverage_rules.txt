# Sync coverage rules (tools/sync_coverage.py -> docs/design/SYNC-COVERAGE.md)
#
# pattern | status | mechanism | note
#   pattern: a full type name (exact), optionally qualified "system:" or "component:", or a prefix ending in "*".
#            First match wins: qualified exact, exact, then the longest prefix.
#   status:  structure, presence, scan, values, keyed, global, actions, statistics, cellmap, terrain, water, movers,
#            icons, clock, derived, snapshot, local, transient, agents, hostonly, excluded, gap (see the script).
# Families (FamilyClassifier/FamilyRules): which entities a component lives on decides its path. Structure entities
# (nets, objects, areas, routes, water sources, mod entities, and since w3/audit events) send every serializable
# component in their structure records; values of non-structure types also travel on the attention values stream.
